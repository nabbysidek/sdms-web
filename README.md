# Student Disciplinary Management System (SDMS)

SDMS is a web-based system designed to efficiently monitor and track student disciplinary records. It provides a structured approach to documenting, analyzing, and managing student misconduct cases, ensuring transparency, fairness, and accountability within educational institutions.

## About the Project

The **Student Disciplinary Management System (SDMS)** aims to streamline the process of handling student disciplinary actions. It enables educational institutions to **log, track, and review** misconduct cases while maintaining a **secure and accessible** record of student behavior. The system ensures that disciplinary actions are documented systematically to promote fair decision-making and compliance with institutional policies.

## Features

Some of the key features of SDMS:

- **Incident Logging** – Record and manage student misconduct cases in a structured format.
- **Student Profile Tracking** – Maintain a history of disciplinary actions associated with each student.
- **Search & Filtering** – Quickly find specific cases using various filtering options.
- **Role-Based Access** – Secure system access with different permission levels for admins, staff, and teachers.
- **Audit Trail** – Maintain transparency by keeping a detailed log of all case updates and modifications.

## Installation

To set up SDMS locally, follow these steps:

1. Clone this repository:
   ```bash
   git clone "https://github.com/nabbysidek/sdms-web.git"
   ```

2. Navigate to the project directory:
   ```bash
   cd sdms-web
   ```

3. Install dependencies:
   ```sh
   npm install
   ```

4. Start the project:
   ```sh
   npm run dev
   ```
